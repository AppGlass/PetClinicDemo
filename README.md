# PetClinic Demo

A Spring Boot application for managing pet owners, visits and clinic room bookings.

Requires Java 17 or newer.

```bash
./gradlew bootRun
```

Open [PetClinic](http://localhost:8080/).
To launch with an operations-supplied room policy, use `./bootstrap_petclinic.sh POLICY_FILE`.
Run `./bootstrap_petclinic.sh --help` for options.
